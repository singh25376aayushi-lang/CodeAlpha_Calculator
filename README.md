# QuantumCalc Pro 🧮

A responsive Scientific & Standard Calculator built with HTML5, CSS3, and Vanilla JavaScript as part of the **CodeAlpha Frontend Development Internship**.

## ✨ Features
- **Dual Mode:** Switch between Standard and Scientific keypads (`sin`, `cos`, `tan`, `log`, `ln`, `√`, `x²`, `xʸ`, `n!`).
- **Angle & Memory Controls:** `DEG` / `RAD` toggle and full memory register support (`MC`, `MR`, `M+`, `M−`).
- **Persistent History Tape:** Automatically saves past calculations in `localStorage` with one-click result reuse.
- **UX Enhancements:** Live expression preview, full keyboard support, and Dark/Light theme switcher.

## 🛠️ Tech Stack
- HTML5, CSS3 (Grid & Custom Properties), JavaScript (ES6+)
